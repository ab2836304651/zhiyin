# 随行心理师 · 轻量级多智能体心理支持原型

这是一个面向心理老师评审的**可交互静态原型**，用于展示“随时可用、持续有耐心、擅长模式推理”的心理支持智能体设计。

本项目不是一个大模型把所有问题都直接回答完的聊天框，而是一个**轻量级多智能体协作系统**：

```text
用户输入
  ↓
总控智能体：理解意图、识别风险、组织任务
  ↓
按需调用：记忆检索 / 线索管理 / 专业分析 / 练习生成
  ↓
监督审查：安全、事实、隐私、表达
  ↓
一段自然且连续的回答
```

## 设计理念

### 1. 轻便、随时可用

- 不要求用户先填写复杂资料；
- 用户可以只说一句话开始；
- 移动端适合快速记录，电脑端适合深度复盘；
- 每次只加载当前问题所需的上下文。

### 2. 发挥 AI 的独特优势

- **耐心**：不因用户重复表达而产生不耐烦；
- **精力**：可以持续陪伴用户做记录和复盘；
- **推理**：帮助发现跨时间的情绪、关系和行为模式；
- **一致性**：不因对话时间或状态变化而完全忘记用户的重要偏好；
- **可及性**：让用户在需要时先获得一个安全的表达入口。

### 3. 多智能体编排，但不增加用户负担

总控智能体只负责编排，不把全部上下文复制给所有模块。不同模块只获得完成任务所需的最小上下文：

| 智能体 | 主要职责 | 典型上下文 |
| --- | --- | --- |
| 总控 | 意图识别、风险优先、任务编排 | 当前输入、对话状态、风险结果 |
| 记忆 | 检索用户主动授权的重要信息 | 相关记忆、用户偏好、目标 |
| 线索 | 提取事实、事件、模式和待验证问题 | 当前话题、近期事件、相关线索 |
| 专业分析 | 睡眠、情绪、关系、优势和资源分析 | 该模块需要的事实和工作假设 |
| 监督审查 | 检查风险、事实、隐私和表达 | 待输出回答、相关事实、审查规则 |
| 教师工作台 | 专业监督、人工接管、案例反馈 | 授权信息、关键线索、风险状态 |

界面中的“本轮协作”会显示本轮实际调用的模块，但用户不需要理解底层编排。

## 已实现的演示能力

- 响应式用户端：手机、平板、电脑均可访问；
- 用户端/教师端角色切换；
- 对话空间：本地模拟智能体回复；
- 多智能体路由演示：不同主题显示不同的协作链路；
- 风险识别演示：出现自伤/轻生相关表达时展示安全确认和现实求助提示；
- 记忆中心：用户主动保存、查看和删除记忆的交互原型；
- 线索图谱：事实、关系事件、资源和工作假设的可视化原型；
- 成长目标：目标进度和今日小行动原型；
- 教师督导：案例队列、风险标签、工作假设和人工接手机制原型；
- 本地演示数据：使用 `localStorage` 保存，不连接真实用户数据。

## 本地运行

需要 Python 3：

```bash
python -m http.server 4173
```

然后打开：

```text
http://localhost:4173
```

也可以使用 npm 脚本：

```bash
npm start
```

## 评审重点

1. 风险识别是否应优先于普通分析；
2. 哪些内容适合写入长期记忆；
3. 线索应如何区分事实、假设和待验证问题；
4. 多智能体编排如何做到“节约上下文”；
5. 教师工作台需要看到哪些信息；
6. 移动端和教师端是否需要不同的信息密度；
7. 系统何时必须转人工或转介专业服务；
8. 哪些 AI 能力可以真正提升心理支持质量，哪些不能替代治疗关系。

## 重要边界

- 本项目不是医疗器械、诊断工具或心理治疗系统；
- 不进行精神疾病诊断、治疗处方或危机风险诊断；
- 真实部署前需要心理教师、系统开发者、法务/隐私负责人共同评审；
- 正式版本需要增加身份认证、加密存储、访问审计、数据保留策略、模型评估和专业人工流程；
- 正式接入大模型后，必须对提示词注入、敏感信息泄露、错误记忆和过度推断进行专门测试。
