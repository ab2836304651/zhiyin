# Zhiyin

> 随时可用、持续有耐心、通过多智能体协作帮助用户探索自己的心理智能体实验室。

`Zhiyin` 是一个开源的开放心理智能体架构原型。它不是学校内部系统，也不是教师审核系统；教师和其他专业人士可以作为使用者、评审者或贡献者参与开源建设。

## 一句话定位

> **让用户选择一个主 Agent 的工作视角，从真实经历出发，逐步探索不同的心理流派和思考路径。**

这里的“流派”首先是一个**组织问题的观察视角**，不是模型自动宣称的完整理论，也不是对用户进行诊断或贴标签。

## 设计理念

### 1. 知音

用户不需要先填写复杂资料，也不必等到正式咨询时间，打开系统就能开始表达。

AI 的价值在于：

- 比人类更稳定的耐心；
- 更持久的注意力；
- 可以随时响应的可用性；
- 能够跨时间整理情绪、关系和行为模式；
- 能够在用户需要时换一种观察角度。

AI 不能替代人的生命经验、专业责任和现实关系。

### 2. 多智能体，而不是一个巨 Agent

总控 Agent 不负责包办所有事情，而是负责：

```text
理解当前输入
  ↓
先做风险与事实边界判断
  ↓
选择本轮真正需要的 Agent
  ↓
给不同 Agent 最小必要上下文
  ↓
汇总、审查、生成自然回复
```

基础 Agent 分工：

| Agent | 职责 | 不应该做什么 |
| --- | --- | --- |
| 总控 Agent | 意图识别、风险优先、任务编排 | 不直接把所有历史塞给所有模块 |
| 记忆 Agent | 检索用户主动授权的偏好、目标和事实 | 不把推断自动变成记忆 |
| 线索 Agent | 整理事件、体验、模式、矛盾和验证问题 | 不把一次经历变成人格结论 |
| 视角 Agent | 根据用户选择的工作视角组织问题 | 不声称自己就是完整理论 |
| 检索/工具 Agent | 调用已审核资料和工具 | 不让外部文本直接成为事实 |
| 输出审查 Agent | 检查风险、事实、隐私和表达边界 | 不替用户做现实决定 |

### 3. 从现实出发，不让模型凭空建立理论

这是本项目最重要的设计纪律之一：

> **模型可以整理、比较、追问和提出假设，但不能因为语言流畅，就把生成内容当作理论依据。**

所有内容在系统内部尽量分成四层：

```text
事实：用户明确说过，或有可追踪来源
体验：用户主观感受到什么
工作假设：基于事实提出的暂时解释
理论引用：经过资料学习、来源追踪和案例验证的内容
```

未经学习、蒸馏和验证的模型输出，不能直接进入正式理论库。

## 用户可以选择的工作视角

当前原型提供以下工作视角：

- 现象探索者：先描述发生了什么；
- 认知观察者：观察想法、解释和重复判断；
- 叙事整理者：观察经验如何被组织成故事；
- 系统观察者：观察关系、位置和互动模式；
- 依恋观察者：观察靠近、回避、期待和安全感线索；
- 优势探索者：寻找已有资源和行动能力。

这些视角是探索入口，不是封闭的理论清单。后续可以由社区贡献新的 Agent，但每个 Agent 都必须说明：

1. 它观察什么；
2. 它不观察什么；
3. 它的依据来自哪里；
4. 它如何避免把推断说成事实；
5. 它如何被实际案例检验。

## 已实现的原型能力

- 手机、平板、电脑响应式界面；
- 用户自主选择主 Agent 的工作视角；
- 对话空间和本地模拟回复；
- 多智能体路由链路展示；
- 风险表达的安全提示演示；
- 用户主动保存的记忆原型；
- 线索、事件和待验证问题展示；
- 成长目标和小行动原型；
- 架构总览：上下文节约、Agent 协作、事实纪律；
- 本地 `localStorage` 演示数据；
- 响应式移动端菜单和视图切换。

当前版本是**架构和交互评审原型**，没有接入真实大模型、真实用户账户或生产级数据库。

## 本地运行

需要 Python 3：

```bash
python -m http.server 4173
```

打开：

```text
http://127.0.0.1:4173
```

也可以使用：

```bash
npm start
```

## 开源边界

- 这不是医疗器械、诊断工具或心理治疗系统；
- 不进行精神疾病诊断、治疗处方或危机风险诊断；
- 不把用户当作被动接受理论的对象；
- 不把模型生成的理论包装成既有理论；
- 任何正式知识模块都需要保留来源、版本、验证记录和不确定性；
- 高风险内容只做安全提示和现实求助引导，不把 AI 伪装成人工危机干预。

## Git

本项目计划以开源仓库形式维护。提交前请确认：

- 不包含真实用户信息；
- 不包含 API Token、密钥或环境变量；
- 不把任何真实心理案例直接公开；
- 涉及理论、案例和知识库时，记录来源和处理过程。
