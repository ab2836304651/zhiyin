# Zhiyin 架构说明

## 1. 总体链路

```text
用户输入
  ↓
交互层
  ↓
倾听与总控 Agent
  ├─ 接住原话和当下处境
  ├─ 维持对话连续性
  ├─ 判断本轮需要什么帮助
  └─ 决定是否调用其他 Agent
       ↓
最小上下文包
  ├─ 记忆 Agent
  ├─ 探索发现 Agent
  ├─ 关联推理 Agent
  ├─ 资料/工具 Agent（可选）
  └─ 边界审查 Agent
       ↓
自然语言回复
```

用户只看到一段连续对话，不需要理解 Agent 数量和底层编排。记忆整理、探索发现、关联推理和边界审查默认作为内隐后台工作，不在对话中频繁提醒用户。

## 2. 为什么不做流派选择器

当前不把用户预先分配给“现象学、认知、叙事、系统、依恋”等固定框架。

原因不是这些内容没有价值，而是：

- 用户可能还没有足够的语言描述自己的经验；
- 单一框架可能遮蔽其他可能性；
- 分类会过早产生“这就是某种类型”的错觉；
- 模型可能在标签上过度发挥，却忽略具体经历。

这些视角以后可以作为：

- 用户主动打开的外部资料；
- 开发者提供的可选 Agent；
- 官方整理的权威参考模块；
- 某次问题确实需要时的工具调用。

但它们不是系统的默认世界观。

## 3. 上下文包

总控 Agent 不把完整会话直接复制给每个模块，而是为每轮生成小型上下文包。

### 倾听/总控包

```json
{
  "current_input": "用户当前输入",
  "session_state": "当前对话阶段",
  "user_intent": "用户此刻可能想表达或行动的方向",
  "risk_signals": ["需要进一步确认的信号"],
  "next_agents": ["memory", "discovery", "review"]
}
```

### 记忆包

```json
{
  "query": "当前问题真正需要的历史信息",
  "authorized_memories": ["与当前问题直接相关的记忆"],
  "implicit_patterns": ["从多次经历中浮现的偏好和重复线索"],
  "excluded_memories": ["敏感、无关或未授权内容"]
}
```

### 探索发现包

```json
{
  "facts": ["用户明确表达的事实"],
  "experiences": ["用户描述的主观体验"],
  "candidate_patterns": ["可能反复出现的关系、想法、情绪或资源"],
  "questions_to_verify": ["下一步需要确认的问题"]
}
```

### 关联推理包

```json
{
  "candidate_connections": ["跨时间或跨事件的可能联系"],
  "alternative_explanations": ["保留多个解释"],
  "evidence_status": "目前有哪些依据，哪些仍未验证"
}
```

## 4. 后台复盘与隐式记忆

对话中的消息在本地自动保存。每轮回复完成后，探索发现 Agent 可以在后台异步运行：

```text
保存当前消息
  ↓
读取最近若干轮对话
  ↓
更新候选模式、体验和资源线索
  ↓
保留来源、时间和待验证状态
  ↓
为下一轮按需检索
```

后台复盘不应该频繁打断用户，也不应该把每一条新发现都推送成通知。只有当用户主动打开发现记录、请求回顾，或者出现必要的安全提示时，才把相关内容呈现出来。

## 5. Agent 协作纪律

### 单一建议源

同一轮多个 Agent 的意见先进入总控汇总，不让多个 Agent 互相覆盖或同时向用户发答案。

### 事实和推断分层

每条分析至少标记为：

```text
事实
体验
候选模式
工作假设
待验证问题
外部资料
```

### 记忆是线索，不是结论

“用户可能比较回避冲突”只能是基于多次经历的工作假设，不能直接成为用户的人格定义。

### 允许模型保留开放性

系统不要求每轮都给出唯一解释。用户可以继续描述、否定、改写或重新定义 Agent 的理解。

## 6. 用户主体性

用户是自己经验的专家。

Agent 的职责是：

- 帮用户记住重要内容；
- 发现用户没有注意到的重复线索；
- 提供不同的观察问题；
- 在必要时寻找外部资料；
- 保护用户不被未经验证的结论束缚。

Agent 不应：

- 代替用户定义自己；
- 把用户归入固定理论；
- 把模型熟悉的名词当成用户的真实体验；
- 用理论权威压过用户的感受和判断。

## 7. 理论准入

模型本身不具备理论权威。理论或方法进入正式知识模块前，至少需要：

```text
资料收集
  ↓
来源登记
  ↓
结构化学习
  ↓
概念边界整理
  ↓
案例对照
  ↓
反例和误判检查
  ↓
版本化发布
```

在此之前，模型生成内容只能作为：

- 临时措辞；
- 对话中的探索问题；
- 未验证工作假设；
- 外部资料检索结果。

## 8. 记忆策略

- 用户明确授权后才写入长期记忆；
- 推断默认不进入长期记忆；
- 记忆必须带来源、时间和敏感度；
- 用户可以查看、修改和删除；
- 相关性优先于数量，避免把整段历史塞回模型；
- 多 Agent 共享的是必要摘要，不是完整私密原文。

## 9. 风险与边界

风险筛查优先于普通分析。

当出现即时安全风险时，系统应当：

1. 停止普通探索；
2. 确认用户当下是否安全；
3. 鼓励联系现实中的支持者和专业资源；
4. 明确说明 AI 不是人工危机干预。

开源版本不提供医疗诊断和治疗处方功能。
